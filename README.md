# Baby Elias ♡

GitHub Pages-ready baby memory website.

## Files
- `index.html`
- `assets/photo.jpg`
- `assets/song.m4a`

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload everything inside this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and open the generated Pages URL.

The **Open Elias's little story** button starts the supplied audio and opens the details section. The music button in the top-right can also play/pause it.
